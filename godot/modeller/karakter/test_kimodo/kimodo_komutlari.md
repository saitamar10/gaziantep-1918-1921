# Kimodo komutları (https://nvidia-kimodo.hf.space)

Her biri için: komut kutusuna çift tıkla → metni yapıştır → Enter → Generate → Exports: Name = dosya adı, Format = BVH → Download.
Kaydedilen .bvh dosyalarını Masaüstüne bırakman yeterli; aktarımı ve Godot sınavını ben yaparım.
